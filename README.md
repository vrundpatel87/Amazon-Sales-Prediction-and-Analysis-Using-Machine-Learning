## 📌 Project Overview

This project focuses on predicting **sales amount** using supervised machine learning techniques. The goal is to analyze how different factors such as product price, discount, category, and ratings influence sales, and to build models that can accurately predict future sales.

## 🎯 Problem Statement

The goal of this project is to build a machine learning model that predicts sales based on various features such as product category, price, ratings, and discount. Accurate predictions can help businesses make better pricing and inventory decisions.

## 📊 Dataset

* **Name:** Amazon Sales Dataset (2025)
* **Description:** Contains product-related information such as price, discount, category, ratings, and sales
* **Dataset Link:** https://www.kaggle.com/datasets/anandshaw2001/amazon-product-sales-2025

## ❓ Research Questions

1. How does product price affect sales?
2. What is the impact of discounts on sales?
3. Which product categories generate the highest sales?
4. Can ratings predict higher sales?
5. Which features are most important for prediction?
6. Which model performs best?
7. How accurately can we predict future sales?

## 🧠 Machine Learning Models Used

* Linear Regression
* Decision Tree Regressor
* Random Forest Regressor
* Support Vector Regressor


## 📈 Evaluation Metrics

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
